# SHUTO 首都 — source

Open-world game set in the real Tokyo metropolitan area (Three.js). iPhone landscape build.

- Play: https://yotanakagawa877-jpg.github.io/shuto/ (gh-pages branch)
- Build: `npm install && MINIFY=1 VERSION=x sh tools/bundle.sh && python3 tools/b64parts.py` -> dist/
- Design, data pipeline and tests: HANDOFF.md
